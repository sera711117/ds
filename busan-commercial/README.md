# 부산 상업용 부동산 상권분석

브라우저에서 실행하는 단일 HTML 대시보드입니다. 별도 설치나 빌드가 필요 없습니다.

## 실행

`index.html`을 브라우저로 여세요. 디자인, JavaScript, 상단 이미지는 파일에 포함되어 있습니다. VWorld 배경지도는 인터넷 연결이 필요합니다.

## GitHub 업로드

1. GitHub에서 새 저장소를 만드세요.
2. 저장소의 파일 업로드 기능에서 이 폴더의 `index.html`, `README.md`, `.nojekyll`을 최상위에 업로드하고 커밋하세요. ZIP 파일 자체를 올리는 것이 아니라 압축을 푼 내용을 올립니다.
3. GitHub Pages 설정에서 브랜치 배포를 선택하고 `main` 브랜치의 루트(`/`) 폴더를 지정하세요.
4. 게시가 끝나면 Pages 설정에 표시되는 주소로 접속하세요.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 데이터와 위치의 한계

- 가격, 거래건수, 인구, 수익률과 관심 건물 비교는 현재 코드에 저장된 예시값이며 실시간 공공데이터 조회 결과가 아닙니다.
- 일부 읍·면·동 위치는 임의 계산값입니다. 실제 건물 위치나 정확한 상권 경계 분석에 사용하지 마세요.
- 지역 목록은 현재 구현된 목록이며 모든 행정동이 검증되어 포함된 것은 아닙니다.
- VWorld 지도 타일의 제공 상태와 접근 정책에 따라 지도가 표시되지 않을 수 있습니다.
- 서버 API나 비밀키는 이 정적 배포에 포함하지 않습니다. 향후 비밀키가 필요한 API는 별도 서버에서 연결해야 합니다.

## 공개 범위

상단 이미지에는 원부동산 상담 전화번호, 이름, 주소 등 기존 상담 안내가 포함되어 있습니다. 공개 저장소나 공개 Pages에 올리면 방문자가 해당 정보를 볼 수 있습니다.
